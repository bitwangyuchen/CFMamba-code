After downloading, place the data into 'data' folder. The structure of the 'data' folder should look like this:
```plaintext
  |-- data
  |   |-- OMSIV
  |   |   |-- X
  |   |   |   |-- [OMSIV input images]
  |   |   |
  |   |   |-- Y
  |   |   |   |-- [OMSIV ground truth]
  |
  |   |-- SDM
  |   |   |-- [SDM test dataset files]
  |
  |   |-- SDM_ref
  |   |   |-- [hyperspectral reflectance files]
  |
  |   |-- split_txt
  |   |   |-- test_list_omsiv.txt
  |   |   |-- test_list_sdm.txt
```
